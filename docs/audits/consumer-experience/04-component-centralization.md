3. **`apps/ui-catalog/src/styles.css` (12 entries):**
   - `.catalog-content > .mw-ui-page-header*` (3 rules), `.catalog-board-metrics .mw-ui-metric-tile-*` (4 rules), `.catalog-board-work-panel .mw-ui-panel-*` (4 rules), `.catalog-form-grid .mw-ui-select-trigger` (1 rule) -> Express via `PageHeader`, `MetricTile`, `Panel` (`density="compact"`), and `SelectTrigger` size props in `@moonwitness/ui`, then remove frozen entries from `scripts/ui-governance-policy.json` in the same PR.

## 3. Sequencing & Guardrails

1. **Wave 1 (Zero-risk additions in `@moonwitness/ui`):** Upgrade `SpeechBubble`, add `ConfirmDialog`, `ErrorState`, `ComicPanel`/`MangaFrame`, `StickerBadge`, `CharacterDisplay`/`CharacterReaction`, `QuestCard`, `AchievementBadge`, `RewardPanel`. Export every new subpath in [`packages/ui/package.json`](../../../packages/ui/package.json) (`check-ui-design-system.mjs` enforces 1:1 TSX-to-export parity).
2. **Wave 2 (Catalog specimens & budget check):** Add lazy specimens or section demos in `apps/ui-catalog` (covering both the 9 currently missing existing components and all new Visual Experience components) while verifying `pnpm test:ui-budget` (`total JS <= 168,000 B gzip`, `initial JS <= 158,000 B gzip`).
3. **Wave 3 (Product adoption in `apps/board` & `apps/desktop`):** Adopt `ConfirmDialog`, `ErrorState`, `Field`, `FilterFacetBar`, `Pagination`, `CharacterReaction`, and `StickerBadge` across `/board/*` routes, retire the 23 frozen CSS overrides, and validate with `pnpm ui:check`, `pnpm test:ui`, `pnpm board:budget`, and `pnpm desktop:test:web`.
