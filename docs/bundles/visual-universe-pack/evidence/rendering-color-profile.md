# Rendering and color profile

## Approved style profile

- **Linework:** confident, clean black-ink contours with stable silhouette edges; vary line weight for foreground/background depth. Keep small details readable at target export size.
- **Cel shading:** one primary shadow family and a limited secondary bounce/highlight; avoid noisy gradients that fight the existing palette.
- **Lighting:** Moon City night key is cool cyan/blue ambient with warm signal-yellow or magenta accents only at selected focal points. Keep light direction consistent across all layers in a scene.
- **Surface:** controlled halftone/photocopy grain and occasional dry-brush/torn-paper edges on separate decorative layers. Do not cover copy, status text, control bounds or faces.
- **Color:** use current approved brand/semantic palette roles. Never use a brand accent to replace semantic state colors.
- **Layering:** preserve alpha and shared scene dimensions/origin; do not flatten layers needed for scene parallax.
- **Typography:** no UI labels, captions, metrics, signage implying factual production data, or dynamic text baked into artwork.

Every production asset should record its renderer/source method, profile revision, source/master relationship, dimensions, palette intent, license and approval status in the existing canonical asset records. Contact-sheet review checks line readability, focal hierarchy, palette consistency and crop behavior. This profile specifies rendering rules; it does not claim new assets exist.
