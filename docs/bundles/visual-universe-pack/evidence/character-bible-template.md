# Character Bible template and depiction policy

This template does not define or select a pilot character. W1-003 character identity work is still subject to explicit user approval for the pilot.

## Identity sheet fields

- Stable `characterId` and revision.
- Role as fictional visual-production metadata only; never bound to a real crew identity or AI provider/model.
- Silhouette description and front/side/back turnaround references.
- Fixed adult/age depiction policy where relevant, height/proportion guide, face/hair, outfit, palette tokens and signature props.
- Allowed pose/expression variants; prohibited variants; scene-lighting adaptations.
- Master asset IDs, generated variant IDs, provenance/licensing and review status.

## Continuity rules

Once approved, the identity sheet is the sole continuity authority. Preserve face, hair, silhouette, body proportions, outfit and props between assets unless a revision is explicitly reviewed. Maintain an anonymous/back-facing option for non-identifiable crew figures. Never generate a recognizable face and treat it as canonical without approval. Do not depict Allah or sacred figures. Do not imply any character is a real crew member.

## Pilot approval boundary

This document defines the schema/policy only. The separate pilot character sheet, identity, face and outfit require user approval before production acceptance or hero use.
