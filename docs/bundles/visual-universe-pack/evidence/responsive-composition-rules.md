# Responsive composition recipes

Composition coordinates are normalized to each artboard; these are authoring guides, not automatic center-crop behavior. Use independent artboards/variants when the focal subject and copy rail cannot both remain safe in a crop.

| Format                 | Composition                                                           | Copy-safe region                                                                      | Focal guidance                                                                  |
| ---------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Wide hero (2:1)        | Horizon in lower third; moon in upper-right; skyline spans frame      | Left 38% remains low-detail for live heading/copy                                     | Keep important silhouette within center 70%; parallax-safe margins at each edge |
| Tall/mobile (4:5)      | Moon above skyline; foreground narrows toward bottom                  | Reserve top or lower overlay rail based on actual page layout; never place baked copy | Keep focal head/brightest landmark inside central 60% width and 65% height      |
| Square (1:1)           | One dominant subject with a compact skyline frame                     | Use a clean side/bottom quadrant selected per placement                               | Keep face/identity only if approved; preserve a 10% safety margin               |
| Editorial panel (16:9) | One readable silhouette and one environmental cue                     | Reserve about one-third for live title where copy overlays                            | Avoid placing focal details under card labels/badges                            |
| Layered scene          | Sky/moon/cloud/back city/near city/foreground share one canvas origin | Copy-safe space is planned in the composition metadata                                | Outer 8% is overscan; clamp camera/parallax to preserve scene coverage          |

Review the actual 375 px, 768 px, and 1440 px catalog checkpoints. Confirm character features only after identity approval. The existing homepage artwork’s desktop/mobile crops remain examples of focal-aware variants; no new hero acceptance is implied by this guide.
