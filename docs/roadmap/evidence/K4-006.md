## Implemented

- Added `packages/research/src/semantics-benchmark.schema.json` (JSON Schema 2020-12) and `validateSemanticsBenchmarkSuite` / `validateHistoricalCountReconciliation` in `packages/research/src/semantics-benchmark.ts`.
- Added `runSemanticsBenchmarkSuite`, which canonically snapshots inputs, validates fail-closed, executes real `@moonwitness/research` evaluators (`projectResearchSemanticAnnotation`, `projectTextualAlignmentCandidate`, `validateConceptProfile` / `validateConceptProfileWithEvidence`) across `measured` cases, keeps `empty`, `unsupported`, and `unknown` slices strictly distinct, computes `precision` / `error_rate` (`null` when `evaluated_cases === 0`), refuses invented passes (`verdict` is `no_measured_cases`, `incomplete`, or `failed` unless all cases are measured and matched), detects caller mutation during async evaluation, and binds outputs with a canonical SHA-256 `report_digest`.
- Added `compareSemanticsBenchmarkReports`, which re-verifies both report digests before comparing, detects `polarity_drift`, `speaker_drift`, `alignment_drift`, `concept_drift`, `coverage_drift`, `verdict_drift`, and `reconciliation_drift`, and emits a digest-pinned `SemanticsDriftLedger`.
- Added `validateHistoricalCountReconciliation`, enforcing that diverging or `historical_unverified` / `unsupported` / `unknown` count observations (including the historical Asma `1751` vs `1754` audit item, `delta = 3`) cannot be marked `reconciled_with_evidence`.
- Added versioned synthetic fixture suite `docs/knowledge/semantics-benchmark-fixtures.json` (`mw:benchmark-suite:synthetic-semantics-v1`, `1.0.0`, `fixture_classification: "synthetic"`), policy documentation in `docs/knowledge/semantics-benchmark-and-drift.md`, and golden evaluation report in `research/evaluations/K4-006-semantics-benchmark.md`.
- Added 6 Vitest tests in `packages/research/tests/semantics-benchmark.test.ts` covering deterministic `report_digest`, `zero_drift` pass, distinct `empty`/`unsupported`/`unknown` handling without invented passes, polarity/speaker/alignment/concept regression drift, coverage drift, and fail-closed rejection of malformed suites, tampered digests, and invalid count reconciliation claims.
