# Evidence K8-006 — editorial/publication revision and takedown support

## Status

- Status: in progress; append-only publication revision superseding, immediate takedown revocation, ETag cache invalidation, immutable audit history (`supersedes_digest`, `takedown_reason_code`, `idempotency_key`), and Fastify API routes/tests are implemented in `@moonwitness/orm-knowledge` and `apps/api`. Board/Web editorial UI (`apps/board/`, `apps/web/`), PostgreSQL integration coverage, and upstream `K8-003`/`K8-004` completion remain open.
- Date: 2026-11-21 (Asia/Jakarta).
- Dependencies: K8-003 (in progress), K8-004 (open).
- Scope: `packages/orm-knowledge/src/publication.model.ts`, `packages/orm-knowledge/src/publication-store.ts`, `packages/orm-knowledge/tests/publication-store.test.ts`, `apps/api/src/routes/publication.routes.ts`, and `apps/api/tests/publication.routes.test.ts`.

## Implemented

- Extended `PublicationSnapshot` (`knowledge.publication_snapshot`) with per-company `idempotency_key` uniqueness (`['company', 'publication_id', 'idempotency_key']`) while preserving append-only ORM and SQL triggers.
- Enhanced `supersedeOrTakedownPublication` in `packages/orm-knowledge/src/publication-store.ts` with idempotent replay verification and conflict detection, appending immutable `approved` (superseded) or `taken_down` (`rights_state: 'withdrawn'`) revisions linked via `supersedes_digest`.
- Added authenticated editorial endpoints in `apps/api/src/routes/publication.routes.ts` (`superadmin` + owning company membership required, `Cache-Control: private, no-store`):
  - `POST /api/research/publications/:publicationId/supersede`
  - `POST /api/research/publications/:publicationId/takedown`
  - `GET /api/research/publications/:publicationId/audit`
- Added `If-None-Match` ETag handling on `GET /api/public/publications/:publicationId` proving stale ETags never return `304` after superseding or takedown (taken-down publications return `404` immediately and disappear from `GET /api/public/publications`).
- Added Vitest coverage in `packages/orm-knowledge/tests/publication-store.test.ts` and `apps/api/tests/publication.routes.test.ts`.
