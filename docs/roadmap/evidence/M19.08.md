## What changed

### Core contract (`packages/orm-isp/src/reconcile.ts`)

- Introduced `DisconnectOutcome = 'acknowledged' | 'rejected' | 'timed_out' | 'no_session' | 'retryable_failure'`.
- `parseDisconnectOutcome(status, body)` requires **both** `sent: true` and `ack: true` for success.
  HTTP 200 without an explicit verified ACK is classified `retryable_failure` — never a completion.
- `dispatchIspDisconnect` returns typed `DispatchIspDisconnectResult` with distinct non-success outcomes:
  - `rejected` — NAK / 4xx other than timeout/no-session
  - `timed_out` — 408/504 or error message mentioning timeout
  - `no_session` — explicit "no active session" error or 404
  - `retryable_failure` — 5xx, malformed body, transport exception
- `processIspRadiusOutbox` uses an **atomic claim** (`claim_token`, UUID) via conditional `UPDATE … WHERE claim_token IS NULL`; a second worker's claim matches zero rows.
- Retry/backoff bounded by `maxAttempts` (default 3) and `retryDelayMs` (default 5s). Claim is released on failure/catch so a crashed worker's row can be retried.
- Result counters: `processed`, `sent`, `acknowledged`, `failed` — only verified ACK increments `acknowledged`.

### Data model (`packages/orm-isp/src/models/index.ts`)

- `ISPRadiusOutbox` status enum expanded to 8 states: `queued`, `pending`, `sent`, `acknowledged`, `rejected`, `timed_out`, `no_session`, `retryable_failure`, `failed`.
- Added `acknowledged_at`, `attempt_count`, `next_attempt_at`, `claim_token`.

### HTTP handler (`packages/orm-isp/src/http.ts`)

- Direct suspend performs a single `suspend + disconnect` call.
- `acknowledged` is scoped outside the try/catch.
- Outbox row is patched to `acknowledged` **only** on a verified ACK.

### Provisioning loop / jobs

- `enforceOverdueSubscriberSuspensions` uses `acknowledged` status and `outcome` field.
- `OUTBOX_PROCESS` aborted result includes `acknowledged: 0`.

### Rust runtime (`apps/isp/src/main.rs`)

- `RecordAccountingParams` moved to module scope (clippy: struct not supported in impl).
- `#[allow(dead_code)]` on unused public types in `control_contract.rs` and `radius_protocol.rs`.
- Collapsible `if` fixes and clippy lints resolved.
