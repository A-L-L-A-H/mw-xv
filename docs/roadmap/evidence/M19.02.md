## Kontrak dan hasil

- Perilaku sebelum: No versioned contract between Go control-plane and Rust ISP runtime existed.
- Perilaku sesudah / deliverable: Versioned Go↔Rust contracts with authenticated transport, bounded deadline, correlation ID, operation ID, idempotency key, config generation, typed outcomes (planned, applied, acknowledged, rejected, timed_out, drifted, rolled_back), separate health signals (liveness, readiness, management reachability, protocol health), typed error codes, and redacted error details. Shared JSON fixtures consumed by both Rust and Go test suites.
- File yang diubah:
  - `apps/isp/src/control_contract.rs` — serde request/response envelopes and validation
  - `apps/isp/src/lib.rs` — library target exposing contract
  - `apps/isp/tests/fixtures/` — 11 self-describing JSON fixtures (4 positive, 7 negative)
  - `apps/isp/tests/control_contract_test.rs` — Rust contract test over fixtures
  - `apps/control-plane/isp/contract.go` — matching Go envelope structs + ValidateRequest
  - `apps/control-plane/isp/contract_test.go` — Go test round-tripping same fixtures
  - `docs/roadmap/20-isp-rust-go-architecture-aaa.md` (M19.02 acceptance checklist updated)
- Public API/schema/config yang terdampak: Control contract schema version `u16` field; receivers reject unknown versions with `unsupported_version`.
- Keputusan dan alasan: Per ADR 0019 "Go-to-Rust contract" section; no TypeScript handler sends device commands directly; pure contract surface only.
