## 3. Recommended Next Vertical Slice (`M13.02`)

### Selection: Read-Only Revision-Pinned Repo Radar Snapshot (`RepoSnapshot` Builder + `R0` Desktop Bridge Surface)

**Why this exact slice (and why only one):**

- **Smallest genuinely missing foundational gap:** `ReadOnlyRepoInspector` (`packages/ai-runtime/src/repo-inspector.ts`) and `WorktreeSandbox` (`apps/desktop/src/worktree-sandbox.ts`) already enforce path allowlists, symlink/junction containment, secret blocking, and bounded reads, yet neither produces a typed, revision-pinned repository snapshot (`RepoSnapshot`) capturing Git revision/dirty state, workspace manifests, runnable scripts, documentation inventory, scan completeness/truncation markers, and a SHA-256 snapshot digest.
- **Prerequisite for downstream missing slices:** Both genuinely missing capabilities — **Overlap Detector** and **Prompt Forge** — depend directly on a trustworthy, revision-pinned `RepoSnapshot` (matching ROCKSOUL FLOW MVP criterion #1). Building `RepoSnapshot` first avoids coupling downstream slices to ad-hoc filesystem walks.

### Acceptance Criteria for `M13.02`

1. `buildRepoSnapshot` operates strictly through `ReadOnlyRepoInspector` (never calling `fs` directly outside allowlist/containment guards) and never invokes shell commands inside `@moonwitness/ai-runtime`.
2. Every manifest, script, and doc claim in `RepoSnapshot` cites an exact relative file path and SHA-256 file digest; direct observations are explicitly separated from inferred metadata.
3. Sensitive paths (`.env*`, `.git/*`, keys, credentials) are excluded unconditionally and never leak into manifests, script values, or error strings; values are passed through `createRedactor()`.
4. When file count or byte caps are reached, `incomplete: true` and explicit `omittedReasons` are recorded rather than silently returning a partial snapshot as complete.
5. In `apps/desktop`, `inspectRepoSnapshot` enforces `DesktopRiskGate` at tier `R0` (`repo.read` / `git.status`), pins the exact Git `headCommit` + `branch` + `dirty` boolean via `execFile('git', ..., { shell: false })`, and preserves tenant `companyId` + `CapabilityGrant` validation.
6. Snapshot output is deterministic for identical inputs (stable sorted arrays and reproducible `snapshotSha256` excluding timestamps when comparing content digest).
