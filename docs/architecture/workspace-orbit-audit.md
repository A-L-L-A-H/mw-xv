## 2. Drift & Gap Inventory

1. **INV-014 HTTP Plugin Migration (Resolved for `workflow` & `project` in `M13.07`):**
   - `packages/orm-workflow/src/http-plugin.ts` and `packages/orm-project/src/http-plugin.ts` replaced legacy `apps/api/src/routes/workflow.routes.ts` and `apps/api/src/routes/project.routes.ts`.
   - Any remaining legacy domain route outside `manifest.httpPlugins` is flagged as `INV014_LEGACY_API_ROUTE_DRIFT` by `auditWorkspaceOrbit`.
2. **Worktree Lease & Hygiene Governance:**
   - Isolated Git worktrees under `apps/desktop` require single-writer lease fencing; dirty unleased worktrees (`DIRTY_UNLEASED_WORKTREE`), duplicate worktree paths (`DUPLICATE_WORKTREE_PATH`), and expired leases (`EXPIRED_WORKTREE_LEASE`) are audited deterministically.
3. **Design Token & Visual DNA Governance (`M13.11`):**
   - Canonical tokens live in `packages/ui/src/styles/tokens.css` and skins in `packages/ui/src/themes/index.ts` (`moonwitness-ink`, `moonwitness-compact`, `moonwitness-high-contrast`).
   - `packages/ai-runtime/src/visual-dna.ts` provides pure, advisory WCAG 2.1 contrast, reduced-motion, provenance, and token-drift checks without introducing a second UI kit.

---

## 3. Reuse Rules

- **No parallel authorities:** Never introduce a second desktop shell, ORM, task database, prompt registry, memory store, or UI token kit.
- **Advisory-only runtime audits:** Both `auditDesignProfileCompliance` and `auditWorkspaceOrbit` emit `advisoryOnly: true` reports with deterministic SHA-256 digests (`reportSha256`) and never mutate repository files or canonical database state.
- **Clean-room provenance:** External references (`sourceKind: 'external_reference'`) never assert `copyRightsGranted: true`.
