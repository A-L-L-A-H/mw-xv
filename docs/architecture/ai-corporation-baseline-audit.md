### 4.3 Baseline Environmental Debt (`AI0.41`)

1. **PostgreSQL & Restore Drill unavailable on local Windows host:** `POSTGRES_TEST_URL`, `DATABASE_URL`, and native `psql` are absent locally (`docker` CLI is present, but no running PostgreSQL test instance was provisioned for this audit). Consequently, `pnpm test:integration`, `pnpm test:restore-drill`, 4 Postgres files in `@moonwitness/orm-knowledge`, and 4 skipped Postgres files in `@moonwitness/api` are deferred to Postgres-enabled CI (`.github/workflows/ci.yml` `postgres-integration`) or a local Postgres test DB.
2. **Windows `@moonwitness/api` worker concurrency:** Locally on Windows, `@moonwitness/api` must run with `--maxWorkers=2` (already codified in `scripts/run-unit-tests.mjs:102`) to prevent worker pool saturation/timeouts; with `--maxWorkers=2`, all 50 non-skipped files (374 tests) pass reliably in ~69s.
3. **Node engine version warning:** Local host runs `Node v24.22.1`, emitting `[WARN] Unsupported engine: wanted: {"node":"22.x"}` (CI runs Node 22).
4. **Offline optional integrations:** Live S3 tests in `@moonwitness/orm-storage` (2 tests) and live Ollama tests in `@moonwitness/local-ai` (16 tests) skip cleanly when those optional external services are absent.
