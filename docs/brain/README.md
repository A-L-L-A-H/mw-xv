# Second Brain — Brain Layer (`docs/brain/`)

Lapisan **Brain** adalah laboratorium sintesis dan perumusan model mental (*associative knowledge graph*). Di sinilah ide dari `docs/raw/` dihubungkan satu sama lain dengan *Task* dan *Wiki*.

## Karakteristik Dokumen Brain
- **Sintesis Konseptual:** Berisi eksplorasi mendalam (misal: analisis trade-off arsitektur, evaluasi strategi multi-tenancy, perumusan algoritma baru).
- **Tautan Dua Arah (*Bi-directional Links*):** Menghubungkan tugas dan dokumentasi dengan notasi `[[Task:AUD-005]]` atau `[[Wiki:architecture]]`.
- **Inkubator Spesifikasi:** Tempat draf pemikiran berkembang sebelum dikristalisasi menjadi Architectural Decision Record (ADR) atau Design Spec resmi.
