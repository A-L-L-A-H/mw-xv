## How to read the catalog

- `USER IDEA` means the owner-originated concept is visible in the supplied prompt or available prior context.
- `REPOSITORY-DOCUMENTED` means the concept has a public repository or target documentation record.
- `PROPOSAL` means the idea has not been approved as an implementation requirement.
- `UNRESOLVED` means the precise relationship, source wording, chronology or canon remains unsettled.
- A row can have more than one source; repeated mentions do not create new idea identities.

## Additions and revision protocol

Append new records with the next unused `IDEA-####` ID. Do not recycle an ID. Record source links, exact original wording where available, first-known date only when evidenced, classification, status, related project IDs and revision history. Conflicting variants remain separate until human review.
