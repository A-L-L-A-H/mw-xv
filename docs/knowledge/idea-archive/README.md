## Classification vocabulary

Each record must retain one or more of these source meanings:

- `FACT` — supported by an inspectable artifact or exact repository state.
- `USER IDEA` — explicitly owner-originated idea or wording.
- `CANON` — only where an owner-locked rule is evidenced.
- `DECISION` — explicit owner decision with source/context.
- `DRAFT` — work under development.
- `PROPOSAL` — proposed, not approved or implemented.
- `ASSUMPTION` — inferred relationship requiring verification.
- `OBSOLETE` — superseded plan kept for history.
- `UNRESOLVED` — conflicting or incomplete evidence.

Additional evidence states: `REPOSITORY-DOCUMENTED`, `USER-REPORTED`, `MISSING`, `REFERENCE-ONLY`, `NEEDS-SOURCE`, `RIGHTS-REVIEW`.

## Non-negotiable archive rules

1. Original wording is retained before any rewrite or synthesis.
2. User ideas are separated from AI suggestions.
3. A README, issue, mockup, plan or test does not by itself prove production deployment or full completion.
4. Story, event, person, text, law, perspective and relationship are separate evidence domains.
5. Character aliases do not establish identity equivalence without a human-reviewed evidence decision.
6. Scripture text, translation, tafsir/commentary, personal reflection, metaphor and fiction remain separate.
7. Unknown source rights or missing consent prohibit copying raw source bytes into a public archive.
8. No private ChatGPT export, personal diary, account export, credential, infrastructure secret or child-sensitive data is copied into this public repository.
9. Existing TaskOS is the only canonical work lifecycle registry. This knowledge archive is not an alternative backlog.
10. No source repository is deleted, force-pushed, or bulk-imported as part of this archive.

The first Library discovery snapshot recorded 94 objects and 63 PNGs. A later complete pagination pass on 2026-11-23 returned **279 root entries (278 files + 1 folder)** and **319 recursive entries (300 files + 19 folders)**. The latest root inventory contains 203 PNG, 33 Markdown, 28 ZIP, 6 JSON, 4 plain-text, 1 DOCX, 1 Python, 1 CSV and 1 unknown-MIME file. The earlier 94-object count is retained as a historical checkpoint; see [Library Source Register](LIBRARY-SOURCE-REGISTER.md) for both snapshots and the qualification.

- The complete ChatGPT account conversation history was not exposed as a single source in this task. The prompt and selected available context were inspected; unprovided exports remain `MISSING`.
- The complete paginated Library inventory is metadata-only. It does not establish that all 300 files were opened, that image-generation prompts and revisions are preserved, or that source rights are cleared.
- Of 280 accessible repository metadata results, 30 were selected for README and root-tree review. The remaining repositories are still metadata-level in this pass.
- Private repositories are counted but not identified in public documents; their code, issue, branch, tag, LFS, packages, artifacts and deployments have not been fully audited.
- Gists, wikis, package registries, container registries, Actions artifacts, Pages, DNS, webhooks, local drives and independent backups require separate access and checks.
- No all-branches mirror, LFS restore, license determination or retirement readiness has been certified.
