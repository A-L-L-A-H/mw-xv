## Version and correction policy

1. First appearance is recorded only when an original transcript, commit, file date or reliable source provides it.
2. A later polished prompt does not replace the earlier source.
3. A source correction is a new revision record; the previous version remains discoverable.
4. Conflicting versions are linked as `CONFLICT`; neither is silently deleted.
5. Repository creation dates, README blob SHAs and last update times are not substitutes for idea first-appearance dates.
6. A summary made from memory is marked as summary/secondary evidence, never as the original wording.
