## 3. Exact copy and text safety

Preserve exact casing and punctuation for source wording, including:
- `SUNSHINE BELONG`
- `FIND LIGHT IN DARKNESS`
- `HOW U REMIND ME`
- `When The Moon Witness, We Share A Message.`
- `Lines — Visual Effect Mansa`

The MoonWitness II source includes a suggested editorial refinement to its tagline. It must remain a proposed edit unless the owner explicitly approves replacing the original wording.

Do not bake changing UI labels or factual research text into source artwork unless the brief intentionally calls for decorative lettering. Keep final text/citations editable and source-attributed.

## 4. Sacred-subject and representation boundaries

- The supplied master prompt prohibits depicting Allah as a human, character or visual object.
- The available prior user context also records a no-visual-depiction boundary for Prophet Muhammad and Isa/Yesus. The complete original conversation text is not part of this source package, so preserve this as a user directive recorded in available context rather than inventing a full source citation.
- Avoid visualizing sacred figures through human portraits, identifiable characters or implied physical forms. Use non-identifying abstract environments, typography, objects or source text only where appropriate.
- Visual metaphor is not theological evidence. Never claim an image represents the divine essence or proves a religious interpretation.

## 5. Copyright, inspiration and asset rights

- Franchise references in the Asmaul Husna #75–81 moodboard are **references only**. Do not reproduce Dragon Ball, Doraemon, Mojacko, Captain Tsubasa, Kiteretsu, Beyblade or Samurai X character art in production.
- Create original, rights-cleared characters and designs rather than traced / near-identical derivatives.
- Music, lyric, celebrity and trademark references need source-specific review; short labels do not establish rights.
- No legacy asset binary, font, sound or prompt pack is copied by this archive pass.

## 6. Existing target asset pipeline to reuse

MW-XV Issue #19 and the existing target asset package define the preferred path:

1. Brief subject, use, composition, aspect, viewport, text-safe areas and prohibited elements.
2. Generate variations using an approved image-generation workflow.
3. Human-review visual quality, readability, originality, theology/safety and rights.
4. Preserve source master; derive optimized sizes/formats.
5. Register approved sources in the canonical `packages/assets/manifest.json`.
6. Preview in the existing UI Catalog / Creative Lab.
7. Verify dimensions, file sizes, orphan/duplicate state and consumer budgets.

Do not create a second asset manager, a mandatory 3D pipeline or a separate Creative Studio app.
