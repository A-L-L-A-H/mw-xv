# Architecture Decision Records (`docs/decisions/`)

Canonical register of Architecture Decision Records (ADRs) for MoonWitness XV.

| ADR                                                                       | Title                                                | Status   | Scope & Summary                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------------- | ---------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [ADR 0001](0001-platform-contracts.md)                                    | Platform Delivery Contracts                          | Accepted | Two-branch (`main`/`dev`) policy, programmatic addon schema/seed installation, GitHub Issues sync, and no staging/production app deployment                                                                                                                                                                                          |
| [ADR 0002](0002-ui-catalog.md)                                            | Interactive UI Catalog                               | Accepted | Component specimen catalog (`apps/ui-catalog`) and visual/accessibility verification                                                                                                                                                                                                                                                 |
| [ADR 0003](0003-docs-portal.md)                                           | Documentation Portal & Generated Reference           | Accepted | Versioned documentation portal (`apps/docs`) and deterministic reference/diagram generators                                                                                                                                                                                                                                          |
| [ADR 0004](0004-knowledge-rebuild-centralization.md)                      | Knowledge Rebuild Centralization                     | Accepted | Centralizes K0–K9 structured knowledge, provenance, and review workflows in PostgreSQL addons                                                                                                                                                                                                                                        |
| [ADR 0005](0005-mizan-evaluation-policy-boundary.md)                      | Mizan Evaluation & Policy Boundary                   | Accepted | Separates deterministic research/Mizan evaluation from runtime mutation authority                                                                                                                                                                                                                                                    |
| [ADR 0006](0006-mandatory-addon-thin-api.md)                              | Mandatory Addon-First Architecture & Thin `apps/api` | Accepted | Requires all domain models/manifests in `packages/*`, keeps `apps/api` thin via `API_ADDONS`, and enforces `INTERNAL_PREFIXES` (`pnpm api:addon:check`)                                                                                                                                                                              |

| [ADR 0008](../architecture/adr/0008-local-first-desktop-agent-harness.md) | Local-First Desktop Agent Harness (`apps/desktop`)   | Accepted | Defines `apps/desktop` (`@moonwitness/desktop`, Tauri v2 + Node `22.x` sidecar), zero overlap with `apps/board`, dual-dialect `~/.moonwitness/local.db` SQLite PCW sync, and `window.__MW_DESKTOP__` (`DesktopCapabilityBridge`)                                                                                                     |

  - Cross-runtime external Agent-to-Agent (A2A) delegation is explicitly **deferred and disabled in v1** per [ADR 0007](0007-ai-corporation-addon-first-architecture.md) D9 and documented in [`docs/ai-corporation/mcp-catalog.md`](../ai-corporation/mcp-catalog.md) §4. Any future proposal to enable external A2A peer federation must allocate **ADR `0009+`** (keeping `ADR 0008` exclusively for the Local-First Desktop Agent Harness).
