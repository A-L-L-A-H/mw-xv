# Blueprint Registry (`docs/blueprints/`)

Direktori ini menyimpan cetak biru (*macro blueprints*) untuk inisiatif besar dan evolusi platform MoonWitness.

## Blueprint Aktif
- `docs/blueprints/ai-corporation-blueprint.md`: Cetak biru tata kelola tenaga kerja otonom AI Corporation (EGAO) berdasar ADR 0007.
- `docs/blueprints/taskos-second-brain-blueprint.md`: Cetak biru Universal ProjectOS, TaskOS v2, dan Second Brain.

## Siklus Hidup Blueprint
`Draft` ➔ `In Review` ➔ `Accepted` ➔ `Implementing` ➔ `Shipped` ➔ `Superseded`.
Setiap section blueprint mengikat task code konkreto di `docs/tasks/tasks.json`.
